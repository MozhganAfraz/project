# project
Open Library Book Fetcher
A Python script that fetches book data from the public [Open Library API](https://openlibrary.org/developers/api), filters books published from the year 2000 onwards, and saves the results to a CSV file.

---

## ✨ Features

- Fetches up to 50 books from the Open Library public API
- Filters books with a publish year ≥ 2000
- Saves filtered results to filtered_books.csv
- Uses the requests library for HTTP calls
- Clean, readable code with proper error handling
- UTF-8 encoding for full Unicode support

 Requirements

- Python 3.6+
- requests library
